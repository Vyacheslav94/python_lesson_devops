3. Создать Jenkins pipeline, pipeline должен уметь разворачивать ELK stack. Если не хватает ресурсов, тогда развернуть только Elasticsearch.
   ELK стек должен разворачиваться на новом слейве.

Вот пример Jenkinsfile, который использовал в pipeline:

pipeline {
    agent any

    stages {
        stage('Preparation') {
            steps {
                script {
                    // Убедитесь, что у вас есть необходимые инструменты
                    sh 'echo "Preparing environment..."'
                }
            }
        }

        stage('Deploy Elasticsearch') {
            steps {
                script {
                    // Команды для установки и настройки Elasticsearch
                    sh '''
                    echo "Deploying Elasticsearch..."
                    # Замените на ваши команды установки
                    docker run -d --name elasticsearch -e "discovery.type=single-node" -p 9200:9200 elasticsearch:7.10.0
                    '''
                }
            }
        }

        stage('Deploy Logstash') {
            steps {
                script {
                    // Команды для установки и настройки Logstash
                    sh '''
                    echo "Deploying Logstash..."
                    # Замените на ваши команды установки
                    docker run -d --name logstash --link elasticsearch:elasticsearch -p 5044:5044 logstash:7.10.0
                    '''
                }
            }
        }

        stage('Deploy Kibana') {
            steps {
                script {
                    // Команды для установки и настройки Kibana
                    sh '''
                    echo "Deploying Kibana..."
                    # Замените на ваши команды установки
                    docker run -d --name kibana --link elasticsearch:elasticsearch -p 5601:5601 kibana:7.10.0
                    '''
                }
            }
        }

        stage('Post-deployment') {
            steps {
                script {
                    // Проверка статуса развертывания
                    sh 'curl -X GET "localhost:9200/_cluster/health?pretty"'
                }
            }
        }
    }

    post {
        always {
            echo 'Pipeline finished.'
        }
    }
}
Объяснение:
Preparation: Подготовка окружения. Здесь можно добавить проверку зависимостей или другие подготовительные шаги.
Deploy Elasticsearch: Этот этап запускает контейнер Elasticsearch. 
Deploy Logstash: Запускает контейнер Logstash и связывает его с Elasticsearch.
Deploy Kibana: Запускает контейнер Kibana и связывает его с Elasticsearch.
Post-deployment: Проверяет статус кластера Elasticsearch, чтобы убедиться, что все работает корректно.
