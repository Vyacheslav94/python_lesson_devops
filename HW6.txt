1. Через volume подкинуть конфиг в nginx контейнер, чтобы на страничке в браузере появилась слово Docker (либо через curl это проверить).
  1) Создал директорию
	mkdir nginx-docker
	cd nginx-docker
  2) Создал файл default.conf в директории nginx-docker со следующим содержимым:

server {
    listen 80;

    location / {
        default_type text/plain;
        return 200 'Docker';
    }
}
  3) Запустил Nginx и подключил мой конфигурационный файл через volume:

	docker run --name my-nginx -v $(pwd)/default.conf:/etc/nginx/conf.d/default.conf -p 8080:80 -d nginx
  4) Проверяем.
	Открыл браузер и перешел по адресу http://localhost:8080
Вижу слово Docker.

2. То же самое сделать через docker-compose.

 1) Создал файл docker-compose.yml в той же директории со следующим содержимым:
	version: '3.8'

services:
  nginx:
    image: nginx:alpine
    volumes:
      - ./default.conf:/etc/nginx/conf.d/default.conf
    ports:
      - "8080:80"
  2) Запустил контейнер с помощью Docker Compose:
